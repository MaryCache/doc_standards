# ロゴ

doc_standards のロゴです。シンボル（書類と、要素をつなぐ線）と文字を横に組んでいます。

## ファイル

| ファイル | 使う場所 |
|---|---|
| `doc_standards.svg` | 明るい背景 |
| `doc_standards-dark.svg` | 暗い背景（文字を `#E6EDF3` にした版） |
| `raw/doc_standards-rough.png` | 元のラフ。組み直しの寸法をここから測っています |
| `build/build_logo.py` | ラフから2つの SVG を組み直すスクリプト |

## 作り方

ラフの線の揺れを写さないように、部品ごとに起こし方を分けています。

- 書類の枠・折り返し・縦の線と丸・3本の棒は、ラフで測った寸法の図形です
- 後ろの2枚の紙は、色の範囲をならしてからなぞっています
- 文字は Nunito（SIL OFL 1.1）の太さ 850 で組んでいます

組み直すときは、Nunito の可変フォントを渡して実行します。

```bash
python build/build_logo.py path/to/Nunito[wght].ttf
```

## 使い方

- 背景の明るさに合わせて2つの SVG を使い分けます。暗い背景に `doc_standards.svg` を置くと、文字が背景に沈みます
- 幅 140px までの表示で、線と文字が読めることを確かめています
- 色・比率を変えたり、部品を並べ替えたりしないでください
